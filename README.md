# AIIO Path

Мобильный тренажёр в стиле Duolingo для подготовки к экзамену **NVIDIA-Certified Associate: AI Infrastructure and Operations (NCA-AIIO)**.

- Путь из 22 уроков по официальной программе (3 раздела с весами 38 / 40 / 22 %), у каждого урока 3 уровня, контрольная в конце раздела
- 197 вопросов на английском с объяснениями на русском, 93 карточки с терминами, сопоставление и «верно/неверно»
- Анимированный маскот «Тензор», тёмный стиль в духе NVIDIA
- Серия дней с заморозками, календарём, вехами, целью серии и напоминанием в календарь
- Задания дня, сундуки, кристаллы и магазин, сердца, XP и уровни, достижения, звуки
- В каждом уроке есть вопрос из прошлых тем (interleaving)
- Интервальное повторение (Лейтнер: 10 мин → 1 → 3 → 7 → 16 дней) и работа над ошибками
- Пробный экзамен: 50 вопросов за 60 минут, разбор по доменам
- PWA: ставится на главный экран телефона и работает офлайн

Чистый HTML/CSS/JS без сборки. Деплой на GitHub Pages через `.github/workflows/pages.yml`.

Запуск локально: `python3 -m http.server` в корне репозитория.

Неофициальный проект, не связан с NVIDIA.
